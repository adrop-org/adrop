# adrop program

The Anchor program behind [Adrop](https://adrop.sh): identities gated by a proof of personhood, campaigns with a USDC
escrow and an audience Merkle root, `pay_view` splitting each qualified view 70% viewer / 20% host / 10% protocol.
Devnet: `BAj8sscSBTkfmcBUySDWBUbiYRcFkP7vH1DQ5HETNpm8`. Docs: https://docs.adrop.sh/protocol/.

`github.com/adrop-org/adrop-program` is a read-only mirror of `programs/` in https://github.com/adrop-org/adrop,
published on every change. Open issues and pull requests there. Build: `anchor build`; test: `anchor test`
(Anchor 1.2, Solana CLI 2.0, Rust 1.99).

Apache-2.0.
